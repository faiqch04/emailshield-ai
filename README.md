# EmailShield AI

EmailShield AI is a deep learning project for detecting phishing emails using a Bidirectional LSTM (BiLSTM) model.

## Features
- Email phishing classification
- Trained TensorFlow SavedModel
- Tokenizer and model metadata
- Python prediction API

## Model evaluation
- Test accuracy: 98.23%
- Architecture: Bidirectional LSTM
- Maximum vocabulary: 20,000 words
- Maximum sequence length: 250 tokens

## Labels
- 0: Safe Email
- 1: Phishing Email

## Disclaimer
